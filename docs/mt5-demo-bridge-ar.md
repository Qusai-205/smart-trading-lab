# مواصفة جسر MT5 Demo المحلي

## الغرض

يوصل الجسر المحلي **طرفية MT5 Demo لدى Equiti Jordan** بلوحة «مختبر التداول الذكي» من أجل قراءة ملخص الحساب والشموع فقط. لا يرسل الموقع أوامر شراء أو بيع أو إغلاق أو تعديل مراكز، ولا يحتاج إلى كلمة مرور MT5 داخل الموقع.

> شغّل الجسر على جهازك الذي يعمل عليه MT5 أو في بيئة موثوقة تخصك. لا تشغّله على جهاز عام، ولا تضع رمز الجسر أو كلمة مرور MT5 داخل ملف يتم مشاركته أو رفعه إلى مستودع عام.

## المصادقة

يحمي الموقع مسار الإدخال `POST /api/mt5/demo/ingest` بالرأس التالي:

```text
x-mt5-demo-token: قيمة MT5_DEMO_BRIDGE_TOKEN
```

ينشأ `MT5_DEMO_BRIDGE_TOKEN` من مولّد كلمات مرور لدى المستخدم ويُحفظ في إعدادات أسرار المشروع فقط. لا يُرسل في الدردشة، ولا يظهر في صفحة الموقع، ولا علاقة له بكلمة مرور MT5.

## حمولة JSON المسموحة

يقبل الجسر البيئة `demo` والوسيط `Equiti Jordan` فقط. يمثل المثال التالي شكلاً توضيحياً للحمولة، وليس بيانات حساب حقيقية:

```json
{
  "broker": "Equiti Jordan",
  "environment": "demo",
  "server": "اسم-خادم-Equiti-Demo",
  "accountLogin": "رقم_حساب_تجريبي",
  "equity": 10000.00,
  "balance": 10000.00,
  "leverage": 100,
  "syncedAtMs": 1760000000000,
  "positions": [
    { "symbol": "XAUUSD", "volume": 0.01, "side": "buy", "profit": 0.00 }
  ],
  "bars": [
    {
      "symbol": "XAUUSD",
      "timeframe": "D1",
      "timestamp": 1760000000000,
      "open": 2000.00,
      "high": 2010.00,
      "low": 1995.00,
      "close": 2005.00,
      "volume": 1000
    }
  ]
}
```

| الحقل | القاعدة الأمنية |
| --- | --- |
| `environment` | يجب أن تكون `demo`؛ يرفض النظام `live` بالكامل. |
| `broker` | يجب أن تكون `Equiti Jordan` ضمن هذا الإصدار. |
| `accountLogin` | رقم الحساب فقط، وليس كلمة المرور. |
| `bars` | يدعم M15 وH1 وH4 وD1؛ يرفض شموع OHLC غير المتسقة. |
| `positions` | للعرض والمراجعة فقط؛ لا يستخدم لإصدار أوامر. |

## خطوات التشغيل الآمن

ابدأ بإنشاء حساب Equiti Demo واختيار MT5، ثم ثبّت طرفية MT5 وسجّل دخولك محلياً. يجب أن يقرأ برنامج الجسر معلومات الحساب والشموع من الطرفية، ويضيف عنوان موقعك إلى قائمة العناوين المسموح بها في إعدادات MT5 إذا كان أسلوب الشبكة المستخدم يتطلب ذلك. أرسل ملخصاً دورياً محدوداً إلى المسار أعلاه، ثم تأكد من ظهور «آخر مزامنة» في اللوحة.

لا تُفعّل مسحاً دورياً أو تنبيهات بريدية قبل التأكد من أن الجسر يعمل على حساب Demo وأن الشموع التي وصلت كافية للتحليل. يحتفظ الموقع ببيانات مزامنة وتحليل محدودة، لكنه لا يحتفظ بكلمة مرور MT5 أو بيانات مصرفية.
